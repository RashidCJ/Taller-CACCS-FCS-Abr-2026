# Hojas de referencia rápida (*cheatsheets*)

Hojas oficiales de Posit (RStudio) — los PDF caben en 1–2 páginas y resumen los verbos esenciales de cada paquete. Útiles como referencia durante la sesión y al volver a R semanas después.

**Fuente**: <https://posit.co/resources/cheatsheets/> · repositorio <https://github.com/rstudio/cheatsheets>
**Traducciones al español**: comunidad voluntaria coordinada por Posit.

**Licencia**: las hojas de referencia son obra de **Posit Software, PBC** y sus colaboradores, distribuidas bajo [**Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**](https://creativecommons.org/licenses/by-sa/4.0/). Esta carpeta redistribuye los PDF sin modificación, manteniendo la atribución a los autores originales. Cualquier adaptación o derivado debe preservar la misma licencia.

## Inventario

| Paquete | Para qué sirve | Inglés (`en/`) | Español (`es/`) |
|---------|----------------|----------------|-----------------|
| **Base R** | Sintaxis fundamental: vectores, listas, indexación, funciones | `base-r.pdf` | `base-r_es.pdf` |
| **dplyr** | Transformación de datos: `filter`, `select`, `mutate`, `group_by`, `summarise`, `join` | `data-transformation.pdf` | `data-transformation_es.pdf` |
| **ggplot2** | Visualización capa por capa: geometrías, escalas, facetas, temas | `data-visualization.pdf` | `data-visualization_es.pdf` |
| **tidyr** | Reestructuración: `pivot_longer`, `pivot_wider`, `separate`, `unite` | `tidyr.pdf` | *(no disponible aún en español)* |
| **readr** | Importación de archivos de texto (CSV, TSV) y exportación | `data-import.pdf` | `data-import_es.pdf` |
| **stringr** | Manipulación de texto y expresiones regulares | `strings.pdf` | `strings_es.pdf` |
| **forcats** | Manejo de variables categóricas (factores) | `factors.pdf` | `factors_es.pdf` |
| **purrr** | Programación funcional: `map`, `walk`, iteración tidy | `purrr.pdf` | `purrr_es.pdf` |
| **lubridate** | Fechas y tiempos | `lubridate.pdf` | `lubridate_es.pdf` |
| **RStudio IDE** | Atajos de teclado, paneles, configuración | `rstudio-ide.pdf` | `rstudio-ide_es.pdf` |

## Notas

- La hoja de **tidyr** no estaba traducida al español al momento de armar este taller (abril 2026). Cuando la comunidad la publique, podrá descargarse desde <https://posit.co/resources/cheatsheets/>.
- Las hojas se actualizan periódicamente. La versión incluida aquí es la vigente al **17 de abril de 2026**. Para versiones más recientes, visiten el repositorio oficial.
- Adicionales que no se incluyeron pero pueden ser útiles: `sf` (espacial), `quarto` (publicación), `shiny` (apps interactivas), `tidymodels` (modelado).
